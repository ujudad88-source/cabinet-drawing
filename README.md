# 함 제작도면 작성기

전기·통신 함체(단자함·분전반) 제작도면을 **현장에서 폰으로 바로 그려 공장에 넘기는** 도구입니다.
손으로 그리던 외형도·정면도·전개도를 치수만 입력하면 A4/A3 도면으로 만들어 줍니다.

설치 없이 브라우저에서 바로 실행되고, 한 번 연 뒤에는 **통신이 끊겨도 동작**합니다.

---

## 빠른 시작

1. 배포 주소를 브라우저에서 엽니다 → `https://<아이디>.github.io/cabinet-drawing/`
2. **아이폰**: 사파리 → 공유(↑) → **홈 화면에 추가** → 아이콘으로 실행
   **안드로이드**: 크롬 메뉴 → **홈 화면에 추가**
3. 치수를 넣고 부속을 얹은 뒤 하단 **공유·저장**으로 카카오톡에 보냅니다

## 기능

### 도면
- **7가지 뷰** — 외형도 / 정면도 / 좌측면도 / 우측면도 / 배면도 / 상·하면도 / 전개도
  원하는 것만 켜면 A4 한 장에 자동 배치 (최대 9분할)
- **3D 미리보기** — 여섯 면을 세워 돌려 봅니다. 끌어서 회전, 두 손가락·휠로 확대
- **외형도 방향 선택** — 좌측면 보임 / 우측면 보임
- **실선·점선 정확 구분** — 보이는 모서리는 실선, 가려지는 모서리는 점선
- **카비넷 투상** — 깊이를 실제의 절반 길이로 그려 정육면체가 정육면체로 읽힙니다
- **표제란** — 현장명·도면번호·품명·규격·수량·척도·작성자·작성일·재질·색상·구성·REV

### 함 구조
- **단 구성(세로 연결)** — 본체 + 풀박스 + 2단·3단을 세로로 이어 붙임
- **열 구성(가로 연결)** — 우측으로 함을 이어 붙임
- 이어 붙인 **각 칸은 독립된 함**으로 취급됩니다. 부속은 소속 칸을 가지고,
  좌우 대칭·속판 자동 크기가 모두 그 칸 안에서 계산됩니다
- **전면 테두리(카바)** 유무와 폭 지정
- **단 좌우 마감카바** 표기 (타공후 카바부착)

### 부속 (12종)
환기루버 · 구멍(앙카/피스) · 키(푸쉬버튼/탈착/푸쉬핸들) · 이중시건장치(가로/세로) ·
명판 · 아크릴창 · 엠보타공 · 케이블 인입타공 · 속판(PVC/철/빼끄) · 접지 · 케이블걸이 · 타공덮개

- **기준면 입력** — "좌측면에서 60, 상단에서 60" 식으로 입력. 우측·하단 기준도 선택
- **잠금** — 위치 이탈 방지. 잠겨도 지시선·명칭은 자유롭게 이동
- **그룹** — 여러 부속을 묶어 함께 이동
- **정렬·균등 배치** — 좌·중·우, 상·중·하, 가로 균등, 세로 균등
- **스냅 가이드** — 끌 때 다른 부속 중심선에 자동으로 붙음
- **기본값 저장** — 자주 쓰는 크기·위치를 종류별로 기억
- **점검 경고** — 칸 이탈·겹침을 자동으로 잡아냄
- 속판 3종은 재질 해칭(빗금·점 패턴)으로 한눈에 구분

### 치수·표기
- 전체 치수는 위·왼쪽, 부속 위치 치수는 아래·오른쪽에 배치해 겹치지 않음
- **치수를 누르면** 어느 부속의 어느 방향 치수인지 표시되고 개별로 숨길 수 있음
- 면 단위 치수 일괄 켜기/끄기
- **지시선·명칭을 끌어서** 겹치지 않게 재배치 (지시선이 따라옴)
- 명칭은 원하는 글자로 변경 가능

### 산출·이력
- **가공 지시표** — 부호 / 부착면 / 외·내 / 명칭 / 규격·타공치수 / 위치 / 수량 / 기준
- **집계표** — 함이 여러 개일 때 번호·품명·규격·수량·합계
- **리비전** — 기록 시점과의 차이를 항목별로 비교. 표제란에 `REV.n`, 바뀐 부속에 △R 표시
- **발송 이력** — 공유·저장할 때마다 자동 기록 (날짜·함·REV·받는 곳·파일명)

### 내보내기
| 형식 | 용도 |
|---|---|
| **PNG** | 카톡에 바로 붙습니다. 함이 여러 개면 여러 장 한 번에 |
| **PDF** | A4/A3 여러 장. 집계표 + 도면 + 가공표 전체 묶음 |
| **SVG** | 진짜 벡터. 확대해도 안 깨지고 캐드·일러스트에서 열립니다 |
| **작업 파일(.json)** | 백업·기기 이전·동료 전달. 불러오면 그대로 복원 |

- A4와 A3는 가로세로비가 같아 **같은 이미지가 양쪽에 꼭 맞게** 인쇄됩니다
- 용지 설정에 따라 해상도가 달라집니다 (A4 299dpi / A3 254dpi)

### 조작
- **자유 확대·이동** — 20%~1200%, 두 손가락·두 번 두드리기·휠·끌기
- **도면 전체화면** (⛶) — 폰에서 도면만 화면 가득
- **되돌리기** 40단계
- 부속 검색 · 면별 필터 · 섹션 접기
- 넓은 화면에서는 왼쪽 도면 고정 + 오른쪽 입력 2단 배치

## 배포 방법

`배포방법.md` 참고. 요약하면 —

1. 깃허브에 Public 저장소를 만들고 **아래 5개 파일을 올립니다**
2. `Settings → Pages → Deploy from a branch → main / (root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 로 열립니다

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 본체. 도면 엔진·UI·내보내기 전부 |
| `manifest.webmanifest` | 홈 화면 앱 정보 |
| `sw.js` | 오프라인 캐시 |
| `icon-180.png` `icon-512.png` | 홈 화면 아이콘 |
| `build.py` | 빌드 스크립트 (아래 참고) |
| `README.md` `배포방법.md` | 문서 |

### 빌드

`index.html`은 아티팩트용 소스에 문서 껍데기(viewport·매니페스트·서비스워커 등록)를
씌워 만듭니다. 소스를 고친 뒤 아래를 실행하면 배포용 5개 파일이 다시 생성됩니다.

```
python build.py
```

> **viewport 메타는 반드시 있어야 합니다.** 없으면 모바일이 화면 폭을 980px로
> 가정하고 축소해 글자가 아주 작게 보입니다. build.py가 자동으로 넣습니다.

## 알려진 제한

- **전개도는 절곡 여유(bend allowance)가 반영되지 않았습니다.** 참고용이며,
  재단 치수는 공장 계산에 맡겨야 합니다
- **데이터는 브라우저에 저장됩니다.** 기록 삭제·저장공간 정리로 지워질 수 있으니
  중요한 작업은 **작업 파일로 내보내 두세요**
- 기기 간 자동 동기화는 없습니다 (작업 파일로 옮깁니다)
- 되돌리기는 40단계이며 다시 실행(redo)은 없습니다
- 부속 기호는 실제 부품을 본떠 그린 것으로, 형상이 100% 같지는 않습니다
